# ⚠️ torch 必须先按机器选对版本，不要直接 pip install torch：
#   CPU（无显卡，最省 ~175MB）：
#     pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
#   NVIDIA（按驱动选 cu121 / cu124，CUDA 库会额外占 3.3GB）：
#     pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu124
#   装完 torch 再装本文件：
#     pip install -r requirements-asr-local.txt
#
# 磁盘参考（实测）：
#   torch(CPU) 175MB + funasr 11MB + cam++ 28MB + fsmn-vad 3.9MB ≈ 0.7–1 GB
#   对比：全本地 GPU 方案（含三份 ASR 模型 + CUDA）约 21 GB
