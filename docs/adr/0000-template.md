# ADR 模板

> 复制本文件为 `NNNN-<短横线标题>.md`，改「状态」与四节内容。
> **四节缺一节就不算 ADR**——尤其「放弃的方案」和「重评条件」，那是半年后唯一能救人的两段。

## 状态

`提议` / `已采纳（YYYY-MM-DD）` / `已废弃（被 ADR-NNNN 取代）`

## 背景

什么现象/压力促使要做这个决定？给可核实的数字或现象，不要写「为了更好」。

## 决策

一句话说清「我们选了什么」。然后列具体落地形态（文件、命令、字段名）。

## 放弃的方案

| 方案 | 为什么放弃 |
|---|---|

**这一节最重要**：不写它，半年后有人会把已经否掉的方案重新提一遍。

## 重评条件

出现什么情况就该重新审视这个决定？写成可观测的触发条件。
