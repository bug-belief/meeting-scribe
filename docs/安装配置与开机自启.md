## 3. 环境准备（以 Ubuntu 24.04 为例）

### 3.1 系统依赖

```bash
sudo apt update
sudo apt install -y ffmpeg python3.11 python3.11-venv python3-pip
ffmpeg -version | head -1     # 必须能看到版本号
```

> Python 建议 **3.10 / 3.11**（`funasr`+`torch` 轮子最全）。3.12 可用但部分依赖需源码编译；3.13 风险更高。
> Windows：`winget install Gyan.FFmpeg` 或下载 zip 后把 `bin` 加进 PATH，并在 `.env` 里写 `FFMPEG_BIN=D:/ffmpeg/bin/ffmpeg.exe`。

### 3.2 Python 环境

```bash
cd ~/meeting-asr
python3.11 -m venv .venv
source .venv/bin/activate

# 先装 torch（按机器选，别直接从 PyPI 装，容易拿到不匹配的 CUDA 版本）
# 纯 CPU：
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
# 有 NVIDIA 显卡（消费级 8GB 显存起步就够，驱动 550+）：
# pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu124

pip install -r requirements.txt
python -c "import torch,funasr;print(torch.__version__, torch.cuda.is_available())"
```

### 3.3 模型（首次运行自动下载，约 1GB）

FunASR 走 ModelScope（`FUNASR_HUB=ms`），默认缓存在 `~/.cache/modelscope`，无需手动下载：

| 模型 | 作用 | 大小 |
|---|---|---|
| `paraformer-zh` | 中文 ASR 主模型 | ~840MB |
| `fsmn-vad` | 语音活动检测（长音频切段，内存不爆的关键） | ~1MB |
| `ct-punc` | 标点恢复（让句子可读、也便于分块） | ~290MB |
| `cam++` | 说话人声纹嵌入 + 聚类 | ~28MB |

国内下载慢可先设镜像：`export MODELSCOPE_CACHE=~/models`（自定义缓存目录），或改用 `FUNASR_HUB=hf`。

### 3.4 GPU 加速

`.env` 里 `ASR_DEVICE=cuda:0`（`auto` 会自动探测）。显存不足时把 `FUNASR_BATCH_SIZE_S` 从 300 降到 120 甚至 60；4GB 显存建议直接 `cpu`。

## 5. 配置

```bash
cp .env.example .env
```

必填只有一项：

```ini
LLM_API_KEY=sk-xxxxxxxx          # DeepSeek 控制台创建
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-flash         # V4.1-Flash；旧名 deepseek-chat 已于 2026-07 下线
LLM_THINKING=off                 # 关闭思考链，否则会白烧输出 token
```

> 换任何 OpenAI 兼容服务（通义、Kimi、本地 vLLM/Ollama 的 `/v1`）都只改这几行；
> 非 DeepSeek 服务端若报 `thinking` 字段未知，把 `LLM_THINKING` 设为 `auto`（代码也会自动降级）。
> 密钥只放 `.env`（已在 `.gitignore` 中），代码里没有任何硬编码。

全部配置项见 `.env.example`，查看当前生效值：

```bash
python config.py
```

## 11. 开机自启

### 9.1 Linux（systemd，推荐）

```bash
sudo cp deploy/meeting-watcher.service /etc/systemd/system/
sudo sed -i "s|/home/<原用户>/meeting-asr|$HOME/meeting-asr|g; s|User=<原用户>|User=$USER|" \
    /etc/systemd/system/meeting-watcher.service
sudo systemctl daemon-reload
sudo systemctl enable --now meeting-watcher
systemctl status meeting-watcher --no-pager
journalctl -u meeting-watcher -f          # 实时日志
```

### 9.2 Windows（任务计划程序）

1. 「任务计划程序」→ 创建任务 → 触发器「登录时」→ 勾选「不管用户是否登录都运行」可选。
2. 操作：程序 `E:\...\.venv\Scripts\python.exe`，参数 `E:\...\watcher.py`，起始于 `E:\...\`。
3. 设置里勾「如果任务失败，每 1 分钟重启，最多 3 次」。
4. 想彻底无窗口：用 `pythonw.exe`，或用 NSSM 注册成服务（`nssm install MeetingWatcher`）。

> Windows 上还有一条捷径：把 `watcher.py` 放到「启动」文件夹的快捷方式里。
