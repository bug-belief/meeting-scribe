未检测

1检测输出设备

浏览器要先拿到一次麦克风授权，才肯告诉你设备的真实名字（否则列表里全是空标签）。授权后立刻释放，不会占用麦克风。

2选择输出设备

要让微信听见，这里必须选 虚拟声卡的播放端。名字容易搞反：

选这个CABLE Input 或 VoiceMeeter Input（名字叫 Input，但它是播放设备）
不要选CABLE Output（那是录音端，给微信当麦克风用的）

3试听

选一段音频播进去。去微信里拨个电话（或发条语音消息试听），对方听到的应该就是这段。

等待操作…

4让它用我的声音说

输入文字，服务器用 CosyVoice2 克隆你的音色合成，再按步骤 2 选的设备播出去。微信那头听到的就是「你」在说。

输出链路：本页 → 虚拟声卡 → 微信麦克风 → 对方
